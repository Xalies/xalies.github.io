MeshVault Connect

Send model downloads and creator packs straight into MeshVault.

MeshVault Connect links your browser to MeshVault. Save supported repository downloads with their page details attached, or bring creator packs in directly from Google Drive and Dropbox.

The extension can target a local desktop app or a MeshVault Server on your network.

What it does

Cleaner downloads from model sites.

Without the extension, a downloaded archive is often just a filename in a folder. MeshVault Connect keeps the context around the model so the library remains searchable and useful later.

Captures model metadata Title, thumbnails, author, source, tags, description with embedded images/videos and more where the site exposes them.
Sends files to MeshVault Downloads can be imported into the desktop app or directed to a MeshVault Server on your LAN.
Lets normal downloads continue If MeshVault is not running or is in read-only mode, downloads are still handled normally by the browser. Current Chrome, Edge, and Firefox builds can optionally save Printables collections without importing them.
Keeps data local Files and metadata are sent to your own MeshVault app or server. MeshVault does not collect your model library.
Imports packs from Google Drive and Dropbox Bring creator packs into the MeshVault folder you choose without first reorganising them in a local downloads folder.
Downloads complete Printables sets In Chrome, Edge, and Firefox, import all model files or one named file group as a structured package rather than clicking each file separately.
Keeps useful supporting files In Chrome, Edge, and Firefox, select Printables “Other files” or MakerWorld documentation and CyberBrick files to include with the primary model download.
Handles owned and purchased models For sites with separate purchase/download pages, MeshVault Connect can use the model page details when the download is started later from your account library. 
Lets you choose the destination workflow Ask for a folder, save to a default folder, create a new folder, or send imports to MeshVault for review later.
Cleans up selected repository pages Hide known advertising elements on selected sites and optionally filter models marked as AI-generated where the site exposes that information.

How it works

How the extension import works.

The extension watches supported model pages, prepares the page metadata, then attaches that metadata when a supported model file is downloaded.

Open a supported model page

MeshVault Connect reads useful page details in the browser, such as the model name, author, description, tags, thumbnails, and source URL.

Download the model file

When a supported file or archive is downloaded, the extension holds the metadata temporarily and displays a small pop-up window.

Choose the destination

The pop-up reads the folders from your desktop app or connected MeshVault Server. Choose an existing folder or create the folder where you want the model placed.

Find it later in MeshVault

The imported model appears with searchable metadata, source links, images, and description content instead of becoming another anonymous download.

Owned and purchased models

Some sites split the model page from the download page.

Sites such as Cults3D and CGTrader can show the model details on one page, then provide the actual files from a separate purchases or downloads area. The extension is built around that flow.

Open the original model page first

Visit the public or owned-model page so MeshVault Connect can read the title, author, source URL, description, tags, and images. Check this page first because some sites provide another download route, such as the three-dot menu on Cults3D.

Then open your purchases or account downloads

Use the site's normal owned-model download page. The extension keeps the recent model-page context ready for the file download.

Download the correct file

When the downloaded archive or model file is captured, MeshVault imports it with the saved page details.

Check the imported source

If an owned-model page offers multiple files, as CGTrader can, confirm that the imported model matches the page details. MeshVault attaches the metadata available from the page, and private or account-only pages may expose less than public pages.

Controls

Capture what you want, pause what you do not.

MeshVault Connect is meant to help with model downloads, not take over every browser download.

  • Enable or disable MeshVault capture from the extension popup.
  • Pause capture for individual supported sites.
  • Show progress while downloads are sent to MeshVault.
  • Detect when MeshVault is not running.
  • Use normal browser downloads when MeshVault is unavailable.
  • Hide selected MeshVault folders or subfolders from the Chrome, Edge, or Firefox destination picker.
  • Enable detailed diagnostic logging only when troubleshooting an import.
  • Reduce visual clutter on supported model pages so browsing stays focused.

App and server targets

Send downloads to the machine that owns the library.

The extension can work with the desktop app on the same computer or a MeshVault Server on the local network.

  • Local desktop app target for normal single PC.
  • LAN server target for a dedicated server on another computer, including a self-hosted setup without a desktop client.
  • Server writes require the server to be unlocked.
  • Remote targets stay local to your network; there is no MeshVault cloud in this workflow.

Privacy

Your downloads go to your MeshVault library.

MeshVault Connect exists to preserve useful download context locally. It does not upload your model files to MeshVault servers because there are no MeshVault cloud servers in this workflow.

  • Model files are sent to your app or local server.
  • Captured metadata is stored in your MeshVault library database.
  • Source URLs are kept so you can find the original page again later.

Requirements

What you need installed.

  • MeshVault desktop app or MeshVault Server installed and running.
  • Chrome, Edge, or Firefox with MeshVault Connect installed, or the Safari extension bundled with MeshVault for macOS.
  • A supported model site and download, or a creator pack available in Google Drive or Dropbox.
  • For server imports, the server must be reachable on the same local network and unlocked for writes.
