Feature spotlight

The workflows that make MeshVault feel different.

The app set explains what each piece does. These are the moments worth showing larger, with feature copy on the left and screenshots or short videos on the right.

Browser to library

The biggest win: save the model page with the model.

MeshVault Connect is the workflow that makes the whole system feel different. Capture the title, author, source URL, tags, description, and gallery images from supported model sites, then see the model appear in the Windows vault with context already attached.

  • Designed for model browsing sessions, not manual spreadsheet-style cataloging
  • Works with MeshVault open or running in the tray
  • Best shown as a short video from Printables or MakerWorld into the app
Downloading a model from Printables into MeshVault with the browser connector.

Import and image generation

Drop in old files and make them look like a library.

Manual imports still matter. MeshVault can index loose files, folders, and archive packages across the supported library formats, even when a specific format cannot be previewed or used for automatic image generation.

  • Import single files or folders
  • Generate thumbnails and extra model views for supported files
  • Use distinct model colors so generated libraries do not all look identical
Importing model files into MeshVault and generating thumbnails automatically.

Model viewer

Preview, measure, inspect, and capture renders.

The viewer gives users confidence before they send a file to a slicer. It supports common mesh/CAD formats, G-code layer inspection, measurement with Ctrl+click, build plate reference, and render capture back into the model gallery.

  • Preview STL, OBJ, 3MF, STEP/STP, GLB/GLTF, PLY, and G-code
  • Measure in metric or imperial units
  • Capture preview renders as model images
Previewing a model in MeshVault and capturing the render as an extra image.

Android browsing and downloading

Keep phone downloads clean instead of trapped.

MeshVault Companion is free with no ads. It keeps a structured model folder on Android so files downloaded on a phone can still be browsed, checked, and moved later without relying on cloud sync.

  • Scoped-storage friendly MeshVault folder setup
  • Browse and download files from the phone-side library
  • Good for users who discover models away from the PC
Browsing and downloading models with MeshVault Companion on Android.

Phone web server

Serve the phone library on local Wi-Fi.

The Companion's local web server lets another device browse and download phone-stored files over the local network. It is a practical bridge for moving models without cloud accounts or extra desktop software.

  • Open the phone-hosted library from a Windows browser
  • Download files from the Android MeshVault folder
  • Useful for quick transfers on the same network
Browsing the phone-hosted MeshVault library from another device on local Wi-Fi.

Useful details

The quieter tools that make a big library manageable.

After the main Windows workflow, these are the practical things that keep MeshVault useful day to day without needing cloud accounts or a locked-in folder structure.

Portable

The database is kept in the library folder so you can use it accross multiple installs and still keep all you library intact.

Preview, measure, and capture

Orbit supported models, inspect the build plate, measure with Ctrl+click, and save preview captures back into the model gallery.

Fill in missing images

When an imported model has no useful thumbnail, MeshVault can generate images for supported geometry or use images already embedded in supported packages.

Archive-aware library

Keep downloaded packages intact while still seeing supported contents, previewing single-model archives, and opening other files with their default apps.

Duplicate and cleanup help

Hash checks help catch duplicate imports, missing files are cleaned from the database, and empty folders can be tidied as the library changes.

Collections and folders

Use real folders for the filesystem and virtual collections for project groups, print queues, favourites, or anything that crosses folder boundaries.

PCBWay prep

Prepare supported files for PCBWay upload. Creates a temp folder on your desktop, extracts the zip files if needed. Temp folders are deleted next time the app is launched
