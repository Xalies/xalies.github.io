MeshVault Hub (Desktop)

Built for large libraries and fast workflows.

The desktop hub manages your vault, handles previews locally, and receives downloads from the extension or your phone.

  • Local asset manager with folders, subfolders, and collections
  • Preview STL, OBJ, STEP, G-code, ZIP and 3MF contents
  • Send models directly to slicers (Cura, PrusaSlicer, Bambu Studio)
  • Mirrors your mobile library with folder structure preserved
  • Works with the browser extension to capture downloads with metadata
MeshVault Android

Browse, capture, and send to desktop.

Use your phone as a focused browser for 3D repositories and send files directly to your PC.

  • Browse supported sites inside the app
  • Auto-detect downloads and capture metadata
  • Import existing files and edit metadata
  • Download straight to desktop
  • Optional Google Drive backup for cloud sync

MeshVault Connector (Browser Extension)

Browser Extension to Organize Downloads Automatically.

The extension captures files and metadata as you download so you always remember what you saved.

  • Send files directly to your MeshVault library (not Downloads)
  • Scrapes title, author, tags, description, and images
  • Create new folders or choose existing ones
  • Optional ad/AI content blocking on supported sites

Integrated web server
