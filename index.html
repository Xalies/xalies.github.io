The MeshVault set

A complete 3D File Manager for Windows, Android, and Browser.

The Windows app acts as your main library hub, while the browser connector and Android companion ensure your 3D models stay organized from download to print.

W

MeshVault for Windows

The primary desktop app for organizing, previewing, and managing your 3D print library.

  • Recursive STL and 3MF folder navigation
  • Advanced 3D previews: STL, OBJ, 3MF, STEP, and G-code
  • Virtual collections and tag-based searching
  • Direct handoff to Cura, PrusaSlicer, and Bambu Studio
  • Secure, local-first database management
A

Android STL Companion

Manage your 3D models on the go with Android storage, discovery, and Wi-Fi sharing.

  • Portable MeshVault folder for phone storage
  • Mobile-optimized native 3D viewer
  • Built-in Wi-Fi web server for local model access
  • Wireless transfer to your Windows vault
  • Compatible metadata structure for easy syncing
C

Browser Connector

Capture model metadata from sites like Printables and Thingiverse before they become mystery files.

  • Automated import of STL downloads
  • Capture title, author, source URL, and thumbnails
  • Save descriptions and tags directly to your vault
  • Works with Chrome, Edge, and Brave
  • Requires MeshVault running on your PC

Local-First Vault

A durable library that travels with your files.

MeshVault is built for makers who value data ownership. Your database lives inside your library root, making your STL vault completely portable.

  • SQLite database stored at .meshvault\meshvault.db
  • Automatic duplicate detection via file hashing
  • Smart cleanup of missing model records
  • Virtual collections without moving physical files
  • Portable vault structure for backup and migration
Metadata management: Store author links, print settings, and model descriptions.
