Drop in old files and make them look like a library.

Model viewer

Preview, measure, inspect, and capture renders.

The viewer gives users confidence before they send a file to a slicer. It supports common mesh/CAD formats, G-code layer inspection, measurement with Ctrl+click, build plate reference, and render capture back into the model gallery.

  • Preview STL, OBJ, 3MF, STEP/STP, GLB/GLTF, PLY, and G-code

Useful details

The quieter tools that make a big library manageable.

After the main Windows workflow, these are the practical things that keep MeshVault useful day-to-day without needing cloud accounts or a locked-in folder structure.

Portable

The database is kept in the library folder so you can use it across multiple installs and still keep your entire library intact.

Preview, measure, and capture

Orbit supported models, inspect the build plate, measure with Ctrl+click, and save preview captures back into the model gallery.

Fill in missing images

When an imported model has no useful thumbnail, MeshVault can generate images for supported geometry or use images already embedded in supported packages.

Archive-aware library

Keep downloaded packages intact while still seeing supported contents, previewing single-model archives, and opening other files with their default apps.

Duplicate and cleanup help

Hash checks help catch duplicate imports, missing files are cleaned from the database, and empty folders can be tidied as the library changes.

Collections and folders

Use real folders for the filesystem and virtual collections for project groups, print queues, favourites, or anything that crosses folder boundaries.

PCBWay prep

Prepare supported files for PCBWay upload. Extracts ZIP archives to a clean temporary folder automatically, which is then safely cleaned up on the next launch.

Frequently asked questions

Have questions? We have answers.

MeshVault is local-first by design. Your models, images, and collections are indexed into a portable SQLite library database (.meshvault/meshvault.db) stored directly inside your library folder. No cloud logins, no mandatory internet connections, and your library can move freely between devices and platforms without losing metadata.

A single direct license key (available as a one-time purchase of $19.99) unlocks the full suite of MeshVault apps, including the Windows desktop client, standalone Windows/Linux servers, and supported Linux desktop builds.

Yes! Because the database file resides inside your library directory, you can place your MeshVault library on a shared cloud network drive (OneDrive, Dropbox, Google Drive), a portable SSD, or sync it continuously with local tools like Syncthing or Nextcloud. Both machines will see the exact same layout and collections.

MeshVault Server is an optional lightweight headless client built for Windows and Linux. It allows you to run your model vault on a dedicated local machine (like a home server, spare PC, or workshop computer). You can then browse the library locally via web browser or connect the desktop clients and browser extension over your local area network (LAN).

Yes! MeshVault Companion is available for Android. It is fully free with no ads or in-app purchases. It allows you to browse, search, and preview 3D models stored on your phone, ZIP/3MF contents, and includes a built-in local web server to easily share files from your phone library to your PC or other local devices.
