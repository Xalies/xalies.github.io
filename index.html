Feature highlights

Useful tools for a growing library.

These are selected highlights for a quick overview. The complete, versioned feature reference covers the desktop apps, Connect, Server, Companion, and every supported file type.

Portable

The database is kept in the library folder so you can use it across multiple installs and still keep your entire library intact.

Preview, measure, and capture

Use the native viewer for common mesh, CAD, and G-code formats, inspect build plates, measure models, and save preview captures back into the gallery. Multi-body 3MF colours and materials are preserved where available.

Multi-plate projects

Move between separate plates in supported 3MF and G-code projects instead of treating a multi-plate job as one undifferentiated model.

Fill in missing images

When an imported model has no useful thumbnail, MeshVault can generate images for supported geometry or use images already embedded in supported packages.

Archive-aware library

Keep downloaded packages intact while still seeing supported contents, previewing single-model archives, and opening other files with their default apps.

Duplicate and cleanup help

Hash checks help catch duplicate imports, missing files are cleaned from the database, and empty folders can be tidied as the library changes.

Collections and folders

Use real folders for the filesystem and virtual collections for project groups, print queues, favourites, or anything that crosses folder boundaries.

Favourites

Mark individual or selected models as favourites and open them from a dedicated quick-access view, including models from a connected server.

Additional watch folders

Index external folders in place without moving their files into the main library. Their thumbnails and local index data stay on that computer.

Smarter browser re-imports

When a MeshVault Connect download already exists, choose whether to update the existing model, keep a new copy, or ask each time.

Local and server libraries together

Connect to a MeshVault Server and browse remote models alongside the local library, with clear remote markers and local slicer hand-off.

Slicer result capture

Track useful output from supported slicers, including print time, filament use, material, layer details, printer settings, and object counts.

PCBWay prep

Prepare supported files for PCBWay upload. Extracts ZIP archives to a clean temporary folder automatically, which is then safely cleaned up on the next launch.

Frequently asked questions

Common questions.

MeshVault is local-first by design. Your models, images, and collections are indexed into a portable SQLite library database (.meshvault/meshvault.db) stored directly inside your library folder. No cloud logins, no mandatory internet connections, and your library can move freely between devices and platforms without losing metadata.

A single direct licence key unlocks supported MeshVault desktop and dedicated server builds. Windows can also use Microsoft Store licensing, while MeshVault Pro purchased on Android can unlock compatible connected apps and servers.

The library is portable because its database stays inside the library folder, so it can move between supported desktop clients on a portable drive. For simultaneous access from multiple computers, use MeshVault Server. File-sync tools may be suitable when only one client uses the library at a time, but concurrent syncing of the SQLite database can cause conflicts.

MeshVault Server is an optional lightweight headless client built for Windows and Linux. It allows you to run your model vault on a dedicated local machine (like a home server, spare PC, or workshop computer). You can then browse the library locally via web browser or connect the desktop clients and browser extension over your local area network (LAN).

Yes. MeshVault Companion is free to install on Android and can browse, search, and preview supported models stored on your phone. MeshVault Pro is available for connected transfers and can unlock compatible MeshVault desktop and server apps.

The current macOS beta is a native Apple silicon build for arm64 Macs. It is free while in beta. Intel Macs are not supported by this release.

04 / NOTES

Before you install.

The short answers to the questions that usually decide whether MeshVault fits a collection.

Where is the library metadata stored?

Inside a portable SQLite database at .meshvault/meshvault.db in the library folder. Models, images, and metadata stay under your control.

Can several computers use the same library?

Use MeshVault Server for simultaneous access. A portable drive works when one desktop client uses the library at a time; concurrently syncing the SQLite database can cause conflicts.

Does MeshVault require an account or cloud service?

No. The core library is local-first and does not require a MeshVault cloud account. Optional store licensing and source downloads naturally use their respective services.

Which Macs are supported?

The current free macOS beta is a native Apple-silicon build for arm64 Macs. Intel Macs are not supported by this release.
