The MeshVault set

Three pieces, one library workflow.

Use the Windows app as the main vault, the browser connector to capture new downloads, and the Android companion when you are browsing, sharing or moving files from your phone.

W

MeshVault for Windows

The main desktop app for organizing, previewing and managing your 3D model library.

  • Folder navigation with recursive counts
  • Tiles, compact tiles and multi-column list views
  • STL, OBJ, 3MF, STEP/STP and G-code preview
  • Collections, tags, descriptions and print settings
  • Send to slicer and PCBWay upload prep
A

MeshVault Companion

The Android side of MeshVault for phone storage, local discovery, Wi-Fi sharing and sending models to your PC.

  • Choose a clean MeshVault folder on your phone
  • Compatible metadata database structure
  • Local network discovery and pairing
  • Built-in Wi-Fi web server for local downloads
  • Send model files and metadata to Windows
  • Transfer status shown in the Windows footer
C

MeshVault Connector

The browser extension that helps capture model pages before they become mystery files in Downloads.

  • Send downloads to MeshVault instead of loose folders
  • Capture title, author, source URL and description
  • Download thumbnails and extra images where available
  • Works with Chrome and Microsoft Edge
  • Requires MeshVault open or running in the tray

How they interact

Capture, organize, preview, print.

MeshVault is built around the real way makers collect files: browser downloads, archive packages, phone transfers, old folders, slicer files and project files all end up in one place.

1

Capture the model

Import files manually, drag and drop a folder, use the browser connector from model sites, send files from Android Companion, or download from the phone's local web server.

2

Keep the context

MeshVault stores metadata, images, source URLs, descriptions, package details and hashes in the portable library database.

3

Preview and print

Preview the model, inspect ZIP or 3MF contents, send files to your slicer, or prepare supported geometry for PCBWay upload.

MeshVault Web from Android

Serve your phone library on local Wi-Fi.

MeshVault Companion includes a built-in Wi-Fi web server. Start it on the phone, open the shown local address from another device on the same network, then browse and download from the phone's MeshVault library.

  • Browse folders, collections and model details in a web dashboard
  • Search and sort the phone library from another device
  • Download one model file directly
  • Download a folder or selected models as a ZIP
  • No cloud account or external hosting required

Windows vault

A local-first library that travels with your files.

MeshVault keeps the SQLite database inside the library root, so the model files and metadata can be copied as one folder. Temporary previews and decoded images stay outside the vault and can be rebuilt.

  • Default library at Documents\MeshVault
  • Database stored at .meshvault\meshvault.db
  • Real Unsorted folder for root-level imports
  • Duplicate detection using file hashes
  • Automatic cleanup of missing model records

Why use MeshVault?

Because 3D model folders get messy fast.

Model downloads often arrive as ZIPs with vague filenames, screenshots, license notes, multiple plates, remixes and print settings. MeshVault gives those files a durable home instead of relying on memory and Downloads-folder archaeology.

  • Remember where a model came from
  • See thumbnails and previews before opening a slicer
  • Group models into virtual collections without moving files
  • Keep older local files and new browser imports together
  • Inspect archive contents without extracting everything by hand

Feature highlights

Built for browsing, collecting and printing.

3D previews

Preview STL, OBJ, 3MF, STEP/STP and G-code. STEP previews are powered by the bundled OCCT bridge, with camera controls, build plate reference, measurement tools and render capture.

Generated model images

Generate default thumbnails and extra preview images for imported models that do not already have metadata images.

Archive inspection

Open ZIP and 3MF packages in-app, preview supported files inside, send archive entries to your slicer, or open unsupported files with their default app.

Collections

Create virtual groups that can contain models from different folders while leaving the actual files where they belong.

Browser metadata

The connector can import titles, authors, source links, descriptions, tags and images so new downloads arrive with context.

Phone companion

Android Companion can use its own clean MeshVault folder, send compatible files and metadata to the Windows app, and serve the phone library to other devices on the same local network.

Browser connector

Import from model sites without losing the source.

The browser connector is for the moment you find a model worth keeping. Send it to MeshVault, choose a folder, and keep the page metadata with the file.

Android companion

Your phone can feed the vault too.

MeshVault Companion is designed for clean phone-side storage, local web sharing, and simple transfer back to the Windows vault. It discovers MeshVault on your local network, pairs when required, and sends files with compatible metadata.

  • Choose a MeshVault folder during onboarding
  • Keep phone imports tidy instead of scattered
  • Send models to the Windows library over local Wi-Fi
  • Start a local web dashboard from the phone
  • Download single files, folders or selected models as ZIPs
  • Use the same broad model-file rules as the Windows app

File support

Indexes the files makers actually collect.
