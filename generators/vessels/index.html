04 / From shape to print

A starting point for your slicer.

Use a calibrated filament profile for temperatures, cooling and flow. Print upright on the flat base using normal slicing; check overhangs for supports. These are suggestions, not an embedded slicer preset. The selected advice is saved in the MeshVault package.

Based on Prusa’s watertight printing guidance. Settings cannot guarantee a leak-free print: inspect the sliced walls and base for gaps, then leak-test over a tray. Watertight does not mean food-safe.

Choose a model format for your slicer or MeshVault package. 3MF stores explicit millimetre units; both formats contain the same shape.

One export. A little more context.

The design travels with its details.

This demo includes a title, source link, generator credit, support link, tags, preview and selected printing advice. The shape parameters are attached as a JSON document, so you can refer to them later.

Printing advice uses printSettingsJson; the generator support link uses exportDonationUrl. These stay separate from the attached design parameters.

An .mvpack is a standard ZIP. All packaging happens on your device. No account or MeshVault API is needed.
