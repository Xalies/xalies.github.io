Where MeshVault fits

For the models
you collect.

MeshVault suits a collection built from model-site downloads, creator packs and files you already own. Keep the images, creator details and instructions with the model, then find it again and open it in your slicer.

Start with a local library on Windows, macOS or Linux. Add Connect for supported web downloads, or an optional server for a shared library on your local network.
