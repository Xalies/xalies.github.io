Frequently asked questions

Common questions.

Your library lives in a folder you choose, with its database stored alongside it. You can browse and organise local models without a cloud account, and move the library folder between supported desktop clients.

A single direct licence key unlocks supported MeshVault desktop and dedicated server builds. Windows can also use Microsoft Store licensing, while MeshVault Pro purchased on Android can unlock compatible connected apps and servers.

The library is portable because its database stays inside the library folder, so it can move between supported desktop clients on a portable drive. For simultaneous access from multiple computers, use MeshVault Server. File-sync tools may be suitable when only one client uses the library at a time, but concurrent syncing of the SQLite database can cause conflicts.

No. Start with the desktop app to organise files on your computer. MeshVault Connect adds downloads and source details from supported model sites. MeshVault Server is optional and lets multiple devices access a shared library on your local network.

Yes. MeshVault Mobile is free on Android and as an iPhone and iPad beta through TestFlight. Both keep an on-device model library for browsing, searching, downloading, and supported previews. Optional MeshVault Pro features are available on Android.

The Mac App Store version runs on Apple silicon and Intel Macs. Separate direct downloads are also available for each architecture. Both options include a seven-day trial.
