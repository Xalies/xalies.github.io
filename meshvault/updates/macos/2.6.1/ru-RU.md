# MeshVault 2.6.1

- Отслеживаемые папки во всех сборках Server. MeshVault Server для Windows, Linux и Docker может индексировать существующие папки с моделями по месту их хранения. Пользователи, вошедшие в систему, могут искать в этих папках, просматривать поддерживаемые модели и скачивать оригиналы. Исходные файлы остаются на своих местах.
- Упрощённая настройка Docker. Откройте Options → Watched folders → Browse mounted folders и выберите папку или вложенную папку, подключённую в Docker.
- Более понятная настройка основной библиотеки. Теперь в настройках сервера указано, куда импортировать и копировать модели и где их организовывать. Там же описано, что происходит при выборе существующей папки. При сканировании отдельные модели из корневой папки могут переместиться в `Unsorted`. Чтобы перенести библиотеку на другой компьютер, скопируйте всю папку вместе со скрытой папкой `.meshvault`.
- Загрузки Docker для AMD64 и ARM64, включая совместимые устройства NAS на ARM64.
- Теперь в библиотеке можно индексировать проекты SolidCraft, Layerling и TweakCAD, в том числе внутри поддерживаемых архивов. Для проекта SolidCraft с сохранённой полигональной сеткой доступен 3D-предпросмотр. Для статического предпросмотра проекта Layerling используется сохранённая миниатюра. Документы и компоненты TweakCAD можно индексировать и находить в библиотеке.
