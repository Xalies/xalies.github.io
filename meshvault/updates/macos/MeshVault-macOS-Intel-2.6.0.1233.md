Model formats and thumbnails

- MeshVault now indexes 98 model and project formats, up from 53, alongside 9 archive formats.
- Added previews and thumbnails for 54 more file extensions. For 42 of those, MeshVault uses the image saved in the file. Examples include Blender, SketchUp, Inventor, SolidWorks drawings, LightBurn and supported resin printer files.
- Added 3D previews for 3DS and VRML meshes, STEP .p21 files, and point clouds including E57, uncompressed LAS, PCD and XYZ. Windows and Linux also support OCCT BREP and BRP previews.
- Anycubic PM and PW saved previews now use transparent backgrounds where the background colour can be identified, while preserving the artwork’s colours. Regenerate an existing thumbnail to apply the change.

Viewer

- Added an orientation cube and a Z-section slider to the standalone Viewer and the New interface’s in-app 3D preview. Jump to a standard view or inspect and measure a model at a selected height.
- The standalone Viewer now checks for updates at launch and from Options. Installation requires confirmation.

Desktop and Safari

- Fixed the New interface on macOS reopening libraries on external drives and migrating the default 3MF conversion setting when switching from Classic.
- Refined thumbnail backgrounds and search keyboard focus in Classic on macOS. The New interface’s Options page hides the donation footer in Store builds.
- Added Nexprint and MakerOnline to MeshVault Connect for Safari, including download and metadata capture from supported model pages.

Server and licences

- Fixed update checks in the Windows and Linux Server launchers so they work without a signed-in browser session.
- Added support for Stripe-issued MeshVault Pro licences in Direct desktop builds and Server, with up to 10 devices per Stripe key. Existing Lemon Squeezy licences continue to work.
