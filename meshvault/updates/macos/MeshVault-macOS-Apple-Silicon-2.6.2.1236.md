# MeshVault 2.6.2

- **Windows Classic.** Fixed the “Unsupported MeshVault preview scene version” error when opening some STL and 3MF previews.
- **MeshVault Server.** Fixed a browser preview error that prevented some large 3MF projects from opening. Previews retain model colours, part placement and plate selection.
