# What’s new in MeshVault 2.4

- **Print queues:** Plan upcoming prints, set quantities and track completed copies. Enable in Options > Library.
- **Model Notes:** Keep notes with your models and pin comments to their surfaces. Enable in Options > Library.
- **Folder projects:** Group a folder into a single project with its own tile and thumbnail.
- **Multi-user support:** Connect to a MeshVault Server using your username and password.
