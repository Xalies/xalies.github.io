# What’s new in MeshVault 2.3

- **MeshVault is now free**.
- **Filament colours** appear in the details panel, using supported 3MF profiles and matched guides.
- **Optional affiliate links help keep MeshVault free.** Turn them off in Options to use standard links.
- **Share complete models with `.mvpack`**, including metadata, images, settings and attachments.
- **Improved 3MF compatibility** with OrcaSlicer, Snapmaker Orca and PrusaSlicer. Choose a temporary conversion, keep an original version, or replace the original.
- General interface improvements and fixes.
