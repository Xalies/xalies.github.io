# MeshVault 2.6.1

### Server and Docker

- **Watched folders on every Server build.** Windows, Linux and Docker servers can index existing model folders in place. Signed-in users can search them, preview supported models and download originals. The source files stay where they are.
- **Easier Docker setup.** Open **Options → Watched folders → Browse mounted folders** to pick a folder or subfolder you’ve mounted in Docker.
- **Clearer main library setup.** Server settings now explain where to import, copy and organise models. They explain what happens when you choose an existing folder, including that a scan can move loose top-level models into `Unsorted`. To move your library to another computer, take the whole folder, including the hidden `.meshvault` folder.
- **Docker downloads for AMD64 and ARM64**, including compatible ARM64 NAS devices.

### CAD project support

- **SolidCraft, Layerling and TweakCAD projects** can now be indexed in your library, including inside supported archives. SolidCraft can show a 3D preview when the project contains a saved mesh. Layerling uses its saved thumbnail for a static preview. TweakCAD documents and components can be indexed and retrieved.

### עברית

- תיקיות במעקב בכל גרסאות השרת. שרתי Windows, Linux ו-Docker יכולים להוסיף תיקיות מודלים קיימות לאינדקס במיקומן הנוכחי. משתמשים שנכנסו יכולים לחפש בתיקיות, לראות תצוגות מקדימות של מודלים נתמכים ולהוריד את הקבצים המקוריים. קובצי המקור נשארים במקומם.
- הגדרה פשוטה יותר של Docker. פתחו את Options → Watched folders → Browse mounted folders כדי לבחור תיקייה או תיקיית משנה שחיברתם ל-Docker.
- הגדרה ברורה יותר של הספרייה הראשית. הגדרות השרת מסבירות כעת לאן לייבא ולהעתיק מודלים ואיך לארגן אותם. הן מסבירות גם מה קורה כשבוחרים תיקייה קיימת. הסריקה עשויה להעביר מודלים שנמצאים ישירות בתיקיית השורש לתיקיית `Unsorted`. כדי להעביר את הספרייה למחשב אחר, העבירו את כל התיקייה, כולל התיקייה המוסתרת `.meshvault`.
- הורדות Docker עבור AMD64 ו-ARM64, כולל התקני NAS תואמי ARM64.
- כעת אפשר להוסיף לאינדקס הספרייה פרויקטים של SolidCraft, Layerling ו-TweakCAD, גם מתוך ארכיונים נתמכים. אפשר להציג תצוגת תלת־ממד של פרויקט SolidCraft אם הוא מכיל רשת שנשמרה. ב-Layerling התמונה הממוזערת שנשמרה משמשת לתצוגה מקדימה סטטית. אפשר להוסיף מסמכים ורכיבים של TweakCAD לאינדקס ולאחזר אותם.
