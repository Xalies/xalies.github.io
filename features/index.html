Quick-start guide

From install to an organised first model.

This walkthrough covers installing MeshVault, adding MeshVault Connect, importing from MakerWorld and Dropbox, and bringing files in manually.

01 / Collect

Library and importing

MeshVault works with normal files and folders. It adds a portable database beside them, then gives you several ways to bring an existing collection, creator pack, or new download into the same library.

Desktop

Portable library

Stores models in a normal folder tree and keeps metadata in .meshvault/meshvault.db inside that library, so the files and database can move together between supported desktop clients.

Desktop

Main and watched folders

Uses one portable main library and can index additional local, external, or network folders in place without moving their files into the main library.

Desktop

Files, folders, and drag-and-drop

Imports one or many files, complete folder trees, or dragged content. Folder structure is retained and loose files can go to Unsorted or the selected destination.

Desktop

Batch-safe importing

Skips duplicate files without interrupting every item, continues past unsupported files, and reports importing, scanning, duplicate names, and thumbnail work separately.

Desktop

Archive preview before import

Shows archive names and contained paths before you decide how a ZIP, RAR, 7Z, TAR, or supported TAR variant should appear in the library.

Desktop

Keep a pack intact

Keeps the original archive as one library model when a creator pack belongs together.

Desktop

Virtual archive models

Keeps the source archive intact while indexing supported contents as individual models with their own metadata, thumbnails, and real nested paths.

Desktop

Split or extract packs

Extracts supported contents as separate models into the current folder, an archive-named folder, or the preserved archive hierarchy, with an option to ignore the first wrapper folder.

Desktop

Reusable archive decisions

Applies one archive choice to the rest of the current batch and remembers the last choice as the next default.

Desktop

Imports to review

Finds undecided archives placed directly in the library and Connect imports deliberately saved for review, without stopping startup with repeated modal prompts.

Desktop

Large-library setup

Counts supported files before indexing a large existing library, then lets you index everything, choose particular folders, or exclude folders you do not want catalogued.

Desktop

Staged, resumable scanning

Discovers files first so models appear quickly, then reads hashes, archive contents, metadata, and thumbnails as resumable background work without repeating completed enrichment.

Desktop

Import controls

Shows file-by-file progress for longer manual imports and lets you pause, resume, stop after the current file, or cancel the operation.

Desktop

Scan and watch

Avoids unnecessary full startup scans, watches configured locations, detects new, changed, and missing files, and can generate missing supported thumbnails during a manual scan.

Desktop

Hidden folders and cleanup

Excludes the recycle bin and configured hidden folders, removes missing records when files disappear, and keeps hidden folders on disk until you choose to index them again.

02 / Find

Browse and organise

The library browser is designed to work at both a quick visual level and a detailed folder level, without hiding the real source location of a model.

Desktop

Three library views

Switches between large visual tiles, compact tiles, and a list view while preserving the selected model and its source-folder context.

Desktop

Search

Searches useful indexed information including titles, authors, tags, descriptions, folders, filenames, and source details.

Desktop

Filters

Filters by file type, source, duplicates, and optional printed status, with remote models clearly marked when a server is connected.

Desktop

Sort modes

Sorts by title, recently added, file size, or grouped folder order. Grouped sorting keeps each folder and its nested content together.

Desktop

All, Recent, Unsorted, Favourites

Provides quick views for the whole library, recent additions, loose imports, and models marked as favourites—including compatible remote models.

Desktop

Real folder management

Creates folders and subfolders, renames, hides, or deletes them, shows nested folder counts, and opens the real containing folder when appropriate.

Desktop

Virtual collections

Creates, renames, deletes, and changes collection thumbnails without moving files. Collections can hold individual models or folder-backed groups including nested and future models.

Desktop

Folder-aware collections

Offers both flat and navigable folder-aware collection views, with folders shown before models at each level.

Desktop

Printed status

Marks models as Unknown, To print, or Printed for simple manual library tracking.

Desktop

Duplicate detection

Uses file-content hashes during scanning and import rather than relying only on names, and exposes a duplicate filter for review and cleanup.

Desktop

Batch Select

Provides an explicit multi-select mode with visible checkmarks, selected counts, favourites, collections, metadata, and other appropriate batch actions.

Desktop

Related files

Finds files related to the selected model and keeps supporting project content reachable alongside the primary printable file.

03 / Describe

Metadata and images

Metadata is stored with the library and can come from repository pages, package contents, generated previews, or your own edits.

Desktop

Complete model record

Stores title, author, author profile, source URL, tags, summary, rich description, print settings, project type, package information, printed status, and slicer results.

Desktop

FDM, resin, and CNC types

Assigns a making workflow to individual models or folders, with a configurable FDM or resin default for unassigned files.

Desktop

Rich description editor

Uses a WYSIWYG editor with headings, emphasis, lists, links, tables, YouTube embeds, undo, and redo while preserving compatible HTML captured from the web.

Desktop

Main and extra images

Stores a main thumbnail and gallery images, supports manual additions, and displays extra images in a selectable strip.

Desktop

Image ordering

Reorders and removes images; promoting any image to the first position makes it the model thumbnail.

Desktop

Batch metadata

Applies selected metadata values to multiple models or every model below a folder, including nested folders.

Desktop

Future-folder rules

Optionally keeps folder-level metadata rules active so chosen values are applied to models discovered there later.

Desktop

Automatic geometry thumbnails

Generates centred renders for STL, OBJ, PLY, GLTF, GLB, DAE, FBX, STEP, and STP in the background.

Desktop

Embedded and derived thumbnails

Uses 3MF plate images, FreeCAD FCSTD thumbnails, G-code/GCO slicer images or a toolpath fallback, and supported models inside archives.

Desktop

Existing image reuse

Prefers an unambiguous matching thumbnail, preview, export, or sole folder image already stored beside a model before spending time generating a new render.

Desktop

Thumbnail controls

Configures render quality, colour, and parallel generation speed; generates images during import or scan; and regenerates thumbnails for a model, folder, or the library with up-axis and image-preservation choices.

Desktop

Preview captures

Saves the current viewer render as the main thumbnail, an extra model image, or a separate screenshot without breaking the inspection workflow.

04 / Inspect

Preview and archives

MeshVault can catalogue far more formats than it renders. Previewable files get native inspection tools; indexed-only files remain searchable and can still open in their normal application.

Desktop

13 preview extensions

Previews STL, OBJ, 3MF, STEP, STP, G-code, GCO, GLB, GLTF, PLY, DAE, FBX, and supported .model archive entries.

Desktop

Model navigation

Rotates, pans, zooms, and fits the complete model in frame with matching interaction directions across the desktop clients.

Desktop

Visual controls

Configures viewer background and model colour, optionally gives separate bodies random colours, and preserves multi-body 3MF colour/material information where available.

Desktop

Bed reference

Displays a build-bed reference for scale and allows measurement points on either the model or the bed.

Desktop

Measurements

Keeps up to three measurements visible at once with distinct colours and selectable metric or imperial units.

Desktop

Multi-plate projects

Switches between plates in supported 3MF and G-code projects instead of flattening a multi-plate job into one view.

Desktop

G-code inspection

Displays toolpaths and layers so generated print files can be inspected from the same library record.

Desktop

Archive browser

Lists supported contents without extracting the whole archive and provides preview, slicer, default-app, and extraction actions where appropriate.

Desktop

Archive preview picker

Opens the only previewable archive entry directly or presents a picker when several models are available.

Desktop

Managed temporary extraction

Extracts only the virtual entry required for preview, export, slicer, or default-app actions, then cleans temporary content after use and on the next launch.

05 / Make

Slicers and manufacturing

MeshVault is not only a catalogue: it hands files to the applications you already use and can associate useful slicer output back with the source model.

Desktop

Separate making applications

Configures different FDM, resin, and CNC applications and uses the model or folder project type to choose the correct one.

Desktop

Program detection

Detects compatible installed manufacturing programs and lets you review or override the applications used for each workflow.

Desktop

Slicer hand-off

Sends supported local, archive-contained, or remote files to the configured slicer; remote files use a managed temporary working copy.

Desktop

ZIP to OrcaSlicer

Optionally sends ZIP files directly to OrcaSlicer; otherwise MeshVault uses its normal archive entry selection and extraction workflow.

Desktop

Slicer result association

Watches supported slicer output after a hand-off and connects the resulting metrics to the original model.

Desktop

Print metrics

Captures print time, filament length, weight, volume and cost, layers, maximum Z, layer height, nozzle size, printer, material, material changes, and multi-object counts when supplied.

Desktop

Tested slicers

Tracks supported output from OrcaSlicer, Bambu Studio, PrusaSlicer, SuperSlicer, Cura, and Creality Print.

Desktop

PCBWay preparation

Prepares STL, OBJ, STEP, STP, and 3MF files for supported PCBWay upload workflows, including temporary conversion or packaging where required.

06 / Capture

MeshVault Connect

The browser extension preserves the context that usually disappears after a download. It can target a running desktop app or an unlocked MeshVault Server on the local network.

Connect

Repository capture

Captures supported downloads from Printables, MakerWorld, Thingiverse, Thangs, MyMiniFactory, CGTrader, GrabCAD, Creality Cloud, Cults3D, Makerables, and Tinkercad.

Connect

Complete Printables downloads

On Chrome, Edge, and Firefox, downloads every model file from a Printables page or only one named file group, preserves that grouping in a ZIP, and imports the result as one organised model package.

Connect

Supporting-file selection

On Chrome, Edge, and Firefox, adds selected Printables “Other files” or MakerWorld documentation and CyberBrick files to the model package instead of leaving useful supporting material behind.

Connect

Google Drive and Dropbox

Brings accessible creator packs from Google Drive or Dropbox into the chosen MeshVault folder without first reorganising them in a downloads folder.

Connect

Captured context

Sends available title, author, author profile, source page, summary, rich description, tags, thumbnail, gallery images, project/print information, and downloaded files.

Connect

Destination modes

Asks for a folder on each download, saves directly to a default folder, or sends models to Imports to review. The save prompt can also create a new folder at the root or inside the selected folder.

Connect

MakerWorld filename cleanup

Optionally replaces opaque MakerWorld download names with useful model-title-based filenames.

Connect

Owned and purchased flows

Handles repositories where the model page and later account-library download are separate, including the distinct Cults3D owned and purchased model flows.

Connect

Import review

Can save captured imports for review so their metadata is already attached while you place them into the right library folder.

Connect

Re-import choices

When a captured download already exists, MeshVault can update the existing record, keep a new copy, or ask each time.

Connect

Local or server target

Sends to the local desktop connector or a selected LAN server, tests the connection, and refreshes the available destination folders. Server writes remain protected by the server PIN and licence/write state.

Connect

Normal-download fallback

Allows the browser download to continue normally when MeshVault is unavailable or rejects the import.

Connect

Optional browser-only tools

When MeshVault is not running, can still save generated Printables collections through Chrome, Edge, or Firefox. Chrome and Edge can also replace opaque MakerWorld filenames with useful model-title names.

Connect

Folder visibility

Hides selected destination folders or only their subfolders from Connect’s folder picker without hiding or changing those folders inside MeshVault.

Connect

Capture controls

Turns capture on or off, pauses individual supported sites, shows and cancels active transfers, clears stored page metadata, and reports when the selected MeshVault target is not running.

Connect

AI-model filter

Optionally hides model cards marked as AI-generated on supported sites that expose a usable AI label.

Connect

Selected-site page cleanup

Hides known advertising elements and obstructive overlays on selected supported repositories for a cleaner browsing and download flow.

Connect

Metadata validation

Tests the current supported model page without downloading a file and reports the scraper, source URL, captured fields, and normalised metadata that would be sent.

Connect

Diagnostic mode

Optionally writes detailed import and download events to the extension service-worker console for troubleshooting, with filenames and source URLs included only while the mode is enabled.

Connect

Browser support

Available for Chrome, Microsoft Edge, and Firefox, with a native Safari extension included in the Apple-silicon macOS client.

Connect

Local-first privacy

Sends files and captured metadata to your own app or server rather than uploading the library to a MeshVault cloud service.

07 / Share locally

MeshVault Server

The optional server hosts a library on an always-on workshop PC, home server, or Docker-capable machine while keeping access on your local network.

Server

Windows, Linux, and Docker

Runs as a dedicated Windows or Linux server build, with a Docker image for compatible self-hosted setups.

Server

NAS-friendly Docker setup

Includes bridge-network guidance for Docker Desktop and a host-network configuration for TrueNAS, Unraid, and Linux NAS hosts where direct LAN discovery is wanted.

Server

Browser library

Provides a local web interface for folder navigation, visual browsing, search, sorting, model details, downloads, metadata changes, and permitted library actions.

Desktop

LAN discovery or manual address

Finds servers on the local network or connects with a manually entered address and PIN, then remembers the connection details in app settings.

Desktop

Local and remote together

Shows remote models alongside the current local library with clear remote markers rather than hiding them under an artificial server folder.

Desktop

Remote library actions

Browses, searches, filters, previews, edits metadata, deletes, creates collections, and generates or uploads missing thumbnails when the connection permits it.

Desktop

Remote importing

Imports files, folders, drag-and-drop content, and Connect downloads to the server when Server import is enabled.

Desktop

Client-assisted server imports

Can use the desktop computer for archive extraction and thumbnail generation during manual server imports, which is useful when the server has limited CPU power.

Desktop

Local slicer for remote files

Downloads a managed temporary copy of a remote model and opens it in the slicer installed on the desktop computer.

Licence

Compatible unlock sharing

A desktop client unlocked with a direct key can unlock a compatible server while keeping PIN authentication and write permission as separate checks.

08 / Mobile

Android Companion

The Companion is a phone-side library and transfer tool for models discovered away from the desktop. Some connected transfer and ecosystem features require MeshVault Pro.

Android

Phone-side vault

Stores a structured model folder on Android and provides visual folders, model tiles, search, sorting, collections, details, sharing, and duplicate cleanup.

Android

Repository browser

Browses supported model repositories in-app and saves downloads with available title, source, creator information, and images.

Android

Mobile preview

Previews supported STL, OBJ, 3MF, STEP/STP, and G-code files with configurable limits, colours, grid, multi-part colours, and G-code layer selection; availability varies by tier.

Android

Archive inspection

Opens ZIP and 3MF packages and lets you inspect or preview supported parts inside.

Android

Metadata and images

Edits model details, tags, descriptions, source links, main thumbnails, extra images, and folder placement.

Android

Local Wi-Fi server

Serves the phone library to a browser on the same network for browsing, details, downloads, selected-model ZIPs, metadata export, and permitted management actions.

Android Pro

Desktop discovery and transfer

Discovers compatible MeshVault apps on the LAN, sends individual models or the phone library to the desktop, and supports automatic backup/sync workflows.

Android Pro

Direct slicer hand-off

Sends a selected phone model through a connected desktop app to its configured slicer.

Android Pro

Ecosystem unlock

Can synchronise a compatible Google Play Pro entitlement to connected desktop and server apps.

09 / System

Platforms, options, and support

Core library outcomes are shared across the desktop clients, while installation, stores, security, startup, tray behaviour, and native pickers follow each operating system.

Windows

WinUI desktop client

Available as a direct installer and Microsoft Store package, with direct-key or Store licensing, startup registration, tray support, and distribution-appropriate updates.

macOS

Native Apple-silicon client

Uses SwiftUI, native menus and lifecycle, security-scoped access for libraries and slicers, Safari Connect, and native Apple-silicon builds. The current beta is free.

Linux

Avalonia desktop client

Uses Linux-native file launching, pickers, desktop/menu integration, DEB packaging, and desktop-environment-dependent tray and startup support.

Desktop

Onboarding

Chooses a language, local library or server, FDM/resin/CNC apps, a default making mode, ZIP-to-Orca behaviour, and an available trial or unlock route.

Desktop

Grouped options

Separates app, library, actions, viewer, connections, and licensing settings rather than presenting one undifferentiated settings page.

Desktop

Cache and database recovery

Opens the settings folder, rebuilds the image cache, and provides a deliberate library-database reset route when local index recovery is required.

Desktop

Layout and onboarding recovery

Resets an off-screen or broken window layout and can rerun onboarding without deleting the library or licence state.

Desktop

Localisation

Supports system-default selection and 13 language families with regional variants, including English, Czech, Danish, German, Spanish, Finnish, French, Hebrew, Norwegian, Dutch, Brazilian Portuguese, Russian, and Swedish.

Desktop

Feedback

Sends optional feedback with app version, platform, and distribution context, with a contact address optional unless an email workflow requires it.

Desktop

Diagnostics

Provides focused logs for startup, scan, import, thumbnails, preview, remote connections, updates, licensing, and Connect, with automatic cleanup of old logs.

Licence

Trial and unlocks

Includes a seven-day desktop/server trial, a $19.99 direct licence key, Microsoft Store licensing on Windows, Android Pro ecosystem activation, and a free Apple-silicon macOS beta.

Privacy

No required account or vendor cloud

The core library stays in your folders and database. An account is not required to catalogue models, and local server access remains under your control.

10 / File support

Every indexed format

Indexing, thumbnail generation, preview, slicer hand-off, and archive inspection are different capabilities. This list separates them so a searchable library entry is not mistaken for a native preview claim.

49 indexed model, CAD, project, and G-code extensions

3DM, 3DS, 3MF, ABC, AMF, BGCODE, BLEND, BLEND1, CATPART, CATPRODUCT, DAE, DWFX, DWG, DXF, F3D, FBX, FCSTD, GLB, GLTF, GCODE, GCO, IAM, IFC, IGES, IGS, IPT, JT, NC, OBJ, OFF, PLY, SAT, SAB, SCAD, SKP, SLDASM, SLDPRT, STEP, STL, STP, USD, USDA, USDC, USDZ, VRML, WRL, X_B, X_T, X3D

Eight indexed archive variants

ZIP, RAR, 7Z, TAR, TAR.GZ, TGZ, TAR.BZ2, TBZ2

Native preview

STL, OBJ, 3MF, STEP, STP, GCODE, GCO, GLB, GLTF, PLY, DAE, FBX, and supported .MODEL archive entries

Generated or extracted thumbnails

Geometry: STL, OBJ, PLY, GLTF, GLB, DAE, FBX, STEP, STP. Embedded or derived: 3MF, FCSTD, GCODE, GCO. Supported entries can also be processed inside the eight archive variants.

Slicer hand-off

STL, 3MF, OBJ, AMF, STEP, STP, GCODE, GCO, BGCODE

PCBWay preparation

STL, OBJ, STEP, STP, 3MF

Why some formats are index-only: a CAD or project file can still be titled, tagged, searched, grouped, collected, opened in its normal application, and kept with related files even when MeshVault cannot render it itself.
