MeshVault today

More than a folder scanner.

The current release is built around two real collection paths: importing creator packs and existing folders, or capturing repository downloads with their page details attached. The same portable library can then stay local, include watched folders, or connect to a dedicated server.

01

Collect

Import files, folders and archives with choices for keeping a pack intact, virtually indexing its contents, splitting models, or extracting its folder structure. MeshVault Connect handles supported repository downloads plus Google Drive and Dropbox packs.

02

Understand

Search titles, creators, sources, tags and descriptions; use automatic thumbnails, rich metadata, favourites, collections, printed status and duplicate filtering across local, watched and remote models.

03

Inspect and make

Preview common mesh, CAD and G-code formats, switch multi-plate projects, measure against a bed reference, capture renders, open files in FDM, resin or CNC tools, and retain useful slicer-output metrics.

04

Expand

Move the portable library between supported desktop clients, add in-place watched folders, or host a shared local-network library with Windows, Linux or Docker server builds and an Android companion.

The honest version

Reasons for—and reasons to look elsewhere.

These are not verdicts. They are practical reasons one product may suit a particular library better than another. Free, open-source and self-hosted tools have genuine advantages that a paid desktop product does not replace.

$19.99 once

MeshVault

Best suited to makers whose collection mixes creator packs, repository downloads, CAD and slicer files—and who want a portable local library that can later extend to a server or Android device.

Choose MeshVault when

  • You want repository downloads to arrive with useful page metadata and images.
  • You need deliberate choices for large creator packs and nested archives.
  • You work with CAD, G-code, slicer results, local clients and optional server libraries.

Consider another tool when

  • You specifically want free or open-source software.
  • You need multi-user permissions, public sharing or federation in a web-first system.
  • AI semantic search, geometry-aware duplicate review, or a full print-planning board matters more than capture and archive workflows.

$34.99 once · early access

Meshory

A strong scan-in-place desktop organiser built for very large existing libraries, with automatic rendering, AI-assisted discovery and more advanced duplicate matching.

Choose Meshory when

  • Your main problem is scanning and rendering a very large folder or NAS library in place.
  • You want optional AI tagging and semantic search using your own OpenRouter key.
  • Geometry-aware duplicate detection and automatic discovery of many slicers are priorities.

Consider another tool when

  • You collect through repository pages or structured creator-pack imports.
  • You need broader CAD/project indexing, G-code inspection or slicer-result capture.
  • You want a dedicated local server, Android companion, or a lower one-time price.

Free · open source

Printventory

A practical free desktop organiser for primarily STL and 3MF libraries, with bulk metadata tools, content-hash deduplication, folder/ZIP bundle previews, slicer hand-off, optional AI tagging and a Docker/server path.

Choose Printventory when

  • Free and open source is a firm requirement.
  • Your library is mainly STL and 3MF and you value tags, designers, notes, print-status tracking and multi-part bundle previews.
  • You want configurable slicer hand-off, optional AI tagging or a Docker/server workflow.

Consider another tool when

  • You need broad CAD, project, G-code and archive support.
  • You want full browser capture rather than limited URL metadata enrichment.
  • You want archive import decisions, native remote-library integration or a portable database stored with the library.

Free · open source · self-hosted

Manyfold

A strong choice for a web-first, genuinely multi-user model library, with access controls, external-service integrations, APIs, optional plugins, model relationships, social features and federation.

Choose Manyfold when

  • You want a shared browser-based library hosted on your own server.
  • Multiple users, permissions, OIDC, public/private sharing or federation matter.
  • You want plugins, an open API, model/remix relationships or direct printer integrations.

Consider another tool when

  • You prefer native desktop clients and a library that moves with its own database.
  • You want repository capture from the browser into the native app.
  • You need desktop preview measurements, slicer-result capture or more guided creator-pack imports.

Free · donation-supported

Orynt3D

A free cross-platform organiser with powerful custom and inheritable import rules, metadata, collections and boolean search—particularly useful for carefully structured miniature collections.

Choose Orynt3D when

  • You want a free native desktop app across Windows, macOS and Linux.
  • Custom import configurations, inheritable tags and boolean search fit your way of organising.
  • You are comfortable capturing preview thumbnails manually.

Consider another tool when

  • You want automatic thumbnails across a wider range of mesh, CAD and G-code formats.
  • You need repository and creator-pack capture, duplicate filtering or slicer-result tracking.
  • You want a working server ecosystem and Android companion today.

Free to 50 files · €20 v1 · €60 lifetime (€45 current offer)

Modelist

A polished cross-platform library with nested and smart collections, three duplicate-finding methods, automatic source enrichment, workshop metadata, portable curation backups and an optional phone/share Inbox.

Choose Modelist when

  • You want a permanent free tier to test every feature on a real small library.
  • Smart collections, fuzzy search and exact/heuristic/perceptual duplicate review are priorities.
  • You value printer/material catalogues, curation backups or opt-in phone-to-desktop sharing.

Consider another tool when

  • You need more CAD/project formats, measurements or G-code layer inspection.
  • You want browser downloads captured automatically with their original context.
  • You need archive treatment choices, a dedicated server, or local Android transfers rather than an opt-in sharing service.

Free · Windows

STLOrganizer

A workshop-oriented Windows organiser with a visual folder-template builder, strong print planning, spool tracking, file metadata and an integrated Cults3D discovery feed.

Choose STLOrganizer when

  • You use Windows and want a free print-planning workspace rather than only a library.
  • Node-based folder templates, bulk file moves and commercial-licence tracking matter.
  • A kanban print queue and filament spool inventory are central to your workflow.

Consider another tool when

  • You need macOS/Linux clients or a portable library across operating systems.
  • You collect CAD, G-code and creator packs beyond STL/3MF/OBJ.
  • You want general repository capture, server-hosted libraries or Android browsing and transfers.
